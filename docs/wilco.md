# Wilco: The Flight Simulator for Coding

!!! note "Editor's Word: Why this matters"
    Learning to code often feels like reading a dictionary—lots of theory, but no conversation. **Wilco** changes this by turning practice into a role-playing game. You join a fictional tech startup, get a "boss" (a chatbot), and solve realistic problems using professional tools. It bridges the scary gap between "I know the syntax" and "I can build software."

??? tip "Free Access for Education"
    GitHub offers free access to Wilco quests through [GitHub Global Campus](https://education.github.com/pack). If you are a student or teacher with a GitHub Education account, you can access premium content for free.

## What is Wilco?

[Wilco](https://www.trywilco.com/) is an immersive learning platform that acts like a flight simulator for software developers. Instead of watching video tutorials or taking multiple-choice quizzes, you are dropped into a simulated workplace scenario.

You become an employee at a virtual company. You receive messages from colleagues (AI bots), face sudden "production outages", and have to fix bugs or build features to save the day.

## How It Works

The experience is designed to mimic a real remote job.

1.  **The Setup:** You don't work in a simplified web browser box. You use **VS Code** and **GitHub**—the actual tools professional engineers use every day.
2.  **The Mission:** A chatbot acting as your manager sends you a message: *"Hey, the login page is broken, and customers are complaining. Can you fix it?"*
3.  **The Quest:** You investigate the code, find the error, and push your fix.
4.  **The Feedback:** An automated system reviews your work instantly. If you fixed it, the "manager" congratulates you. If not, they give you a hint.

!!! info "It's Not Just About Code"
    Wilco teaches the "soft skills" of engineering that textbooks ignore:
    
    *   **Communication:** Deciphering vague instructions from a manager.
    *   **Prioritisation:** Deciding what to fix first when everything is breaking.
    *   **Debugging:** Hunting down errors in a messy, existing codebase rather than writing perfect code from scratch.

## Who Is This For?

*   **Students & Beginners:** If you have learned the basics (variables, loops, functions) but feel overwhelmed by real projects, this provides a safe environment to mess up and learn.
*   **Educators:** It serves as an excellent "lab session" where students can apply theory in a controlled, realistic setting without you needing to grade every line of code manually.
