# How to Transfer Past Conversations's Context in a New Chat / to a New Model?

!!! info "Original Source"
    From [X](https://x.com/SmokeAwayyy/status/1902477940325282195), serving as a starting point,.

!!! quote "Editor's Note"
    This technique solves one of the most frustrating times of AI assistants: their inability to remember previous conversations once you start a new chat. With this simple prompt, you can create a seamless experience across multiple sessions.

    Chatbots are designed to treat each chat as a separate conversation, with no memory of previous interactions. This prompt works by creating a comprehensive summary that captures not just the factual content of your conversation, but also the communication style, formatting preferences, and relational dynamics you've established. When pasted into a new chat, it effectively transfers the "personality" of your AI assistant along with the context of your previous discussions. 
    
    

???+ tip "The Memory Transfer Prompt"

    Try below prompt to save the context from a long chat:

    ```
    Summarize this entire conversation with equal weight given to all topics covered, maintaining their full context regardless of when they were discussed. Preserve your response format, tone, and conversational style from this chat so that if I were to restart in a new session, it would feel like I'm continuing with the same version of you from this conversation.
    ```

    Then copy/paste the response into a new chat.
